## 계산 규칙 (기존 동작 보존)
하루 기준액 = floor(월 예산 / 월 일수).
오늘 시작 배정액 = 하루 기준액 × 월중 일자 - 전날까지 해당 월 지출 합계.
오늘 남은 금액 = 오늘 시작 배정액 - 오늘 지출.
음수는 초과 지출 상태로 유지. 월초 이월은 0, 지난달 이월 없음. 월 예산을 나눈 나머지는 미배정 잔액으로 표시하며 임의 말일 지급 없음. 미래일자 지출은 해당 날짜에서 반영. 예산 없을 때 배정액은 미설정으로 표시하며 지출 기록은 허용한다.

예: 30일 월, 예산 300,000원, 1일 12,000원 사용 → 2일 시작 8,000원. 2일 3,000원 사용 → 남은 금액 5,000원. 3일 시작 15,000원.

## 공통 규칙
서버가 인증 회원 ID를 결정하며 클라이언트의 memberId는 받지 않는다. 모든 변경 폼에 CSRF 토큰. 카테고리 소유권과 활성 여부 확인. 비활성 카테고리의 과거 기록은 보존한다. 시각 기준 Asia/Seoul.

## 알림
- N01: 매일 오전 7시(Asia/Seoul), 전체 회원에게 오늘 남은 금액의 스냅샷을 Spring Batch chunk=100으로 저장한다. 예산이 없으면 설정 안내를 저장한다.
- N02: `/notifications`에서 본인 알림을 최신순으로 조회하고 읽음 처리한다. 회원·날짜별 중복 저장을 방지한다.
