# 연도별 색상 테마 관리

## 2027 테마 근거

WGSN·Coloro는 2025-04-29 발표에서 2027년 예측 색상으로 **Luminous Blue**, Coloro **125–28–38**을 선정했다. 이는 WGSN·Coloro의 전망이며 모든 기관이 공통으로 선정한 색이나 Pantone 선정색이라는 뜻은 아니다.

출처: [WGSN 공식 발표](https://www.wgsn.com/de/node/2457).

프로젝트는 이를 참고한 웹용 블루 팔레트를 사용한다. CSS의 HEX 값은 화면 대비와 상태 표현을 위한 프로젝트 해석이며 Coloro 공식 HEX 변환값이라고 주장하지 않는다.

## 구성과 교체

- `src/main/resources/static/css/themes/2027.css`: 연도별 의미 기반 색상 토큰.
- `src/main/resources/static/css/theme.css`: 활성 테마를 import하는 진입 파일.
- `src/main/resources/static/css/app.css`: 레이아웃/컴포넌트, 색상은 토큰 참조.
- JSP는 theme.css 뒤에 app.css를 로드한다.

다음 연도의 공식 전망을 확인한 후 `themes/2028.css`를 만들고 기존 토큰 이름을 유지한다. theme.css의 import 경로 한 줄을 변경하면 화면별 JSP를 수정하지 않고 전환할 수 있다. 연도 변경만으로 자동으로 테마가 바뀌지는 않는다. 빌드/컨테이너 갱신 후 브라우저 캐시도 새로고침한다.

## 검증 체크리스트

- 본문·버튼 텍스트 대비 4.5:1 이상, 컨트롤 경계·포커스 3:1 이상.
- 선택일/오늘/초과 지출/오류는 색상뿐 아니라 라벨·선택 컨트롤로 구분.
- 가계부·카테고리·알림과 로그인·가입·오류 화면을 함께 확인.
- 데스크톱1440px, 모바일390px/320px, 확대 시 여백/잘림 확인.
- 날짜 모달과 월 예산 모달의 배경·입력·오류·비활성 버튼 확인.
- 테스트 팔레트로 전환이 실제로 적용되는지 확인하고 지정 연도로 복원.

일반 배경/강조색과 성공·오류 등 의미 색을 분리한다. 트렌드를 적용하려고 모든 텍스트나 위험 상태를 같은 파란색으로 만들지 않는다.
