# 화면정의

업무용 웹앱 방향: 일별 가계부가 중심이고 입력은 모달에서 수행한다. 밝은 배경, 명확한 표와 라벨, 한글 금액·날짜, 키보드 접근을 유지한다. 2027 Luminous Blue에서 영감을 받은 웹용 테마를 사용하며 실제 S2B 화면/상표를 복제하지 않는다. JSP는 WEB-INF/views에 두고 Controller를 통해 접근한다.

| 화면 | URL | 내용/행동 |
|---|---|---|
| 로그인 | GET /login | 이메일·비밀번호, 가입 이동, 인증 실패 메시지 |
| 회원가입 | GET /signup | 이름·이메일·비밀번호·확인, 검증 오류, 성공 시 로그인 이동 |
| 가계부 | GET /budget?ym=YYYY-MM | 월 선택, 네 요약 카드, 간결한 오늘 안내, 날짜 선택형 일별 표 |
| 선택일 상세 모달 | 가계부 내부 | 선택 날짜 지출 목록, 등록·수정·삭제 확인, 카테고리 즉시 추가 |
| 월 예산 모달 | 가계부 내부 | 조회 중인 월의 예산 생성/수정 |
| 지출 상세/수정 | GET /budget/spends/{id} | 날짜·카테고리·금액·메모, 수정/삭제, 목록 복귀 |
| 카테고리 | GET /categories | 공용·개인 분류, 추가/이름 변경/활성 상태 |
| 알림 | GET /notifications | 날짜별 시작 배정액, 읽음 표시·처리 |
| 오류 | 오류 상태별 JSP | 검증/권한/없는 항목/서버 오류, 안전한 안내와 복귀 |

첫 화면은 실제 오늘이 속한 월에서 오늘 금액을 표시한다. 다른 월은 해당 월 내역과 일별 계산을 표시한다. 미설정 예산에는 설정 안내, 내역 없을 때 빈 상태 안내. 알림의 생성 당시 값과 지출 후 현재 남은 금액은 명칭으로 구분한다.

## 날짜 중심 사용 흐름

1. 현재 월은 오늘, 다른 월은 1일이 기본 선택된다.
2. 날짜 행을 한 번 클릭하면 선택만 바뀐다. 더블클릭 또는 '선택일 상세' 버튼으로 모달을 연다. 모바일은 탭으로 선택하고 버튼으로 연다.
3. 상세 모달은 해당 날짜 내역을 표시한다. 지출 입력 버튼으로 입력 영역을 펼친다. 날짜는 선택일로 고정하며, 다른 날짜는 모달을 닫고 선택한다.
4. 필요한 분류가 없으면 입력 중 카테고리를 생성한다. 새 분류가 자동 선택되고 금액·메모는 유지된다. 카테고리는 별도 저장되므로 지출을 취소해도 남는다.
5. 저장·수정·삭제 후 모달을 유지하고 서버에서 월 요약을 다시 받아 표와 네 요약을 함께 갱신한다. 지출 수정은 분류·금액·메모만 변경한다.

가계부는 `/budget/ui/**` 요청으로 화면을 유지하며 작업한다. 카테고리 관리·회원·기존 MVC 경로는 POST→redirect→GET 흐름을 유지한다. 초안은 페이지 메모리에만 보관하며 새로고침/재로그인 후 복원되지 않는다. 실패 시 자동으로 저장을 재시도하지 않는다.

## 접근성과 반응형

가계부·카테고리·알림은 공통 헤더/푸터 및 최대 1240px 본문 폭을 사용한다. 작은 화면에서는 표 내부만 가로 스크롤한다. 모달은 제목, 닫기 버튼, Escape, 초점 복귀, 오류 안내를 제공한다. 저장 중에는 중복 제출과 닫기를 차단한다. 미저장 변경은 닫기 전 폐기 확인을 받는다. 색상 외 선택 컨트롤과 텍스트로 상태를 구분한다. 모바일 길게 누르기 및 달력 격자는 이번 범위에 포함하지 않는다.
